# 服務員工時 Excel 驗算

純前端的服務紀錄總表驗算工具。Excel 檔案只在瀏覽器本機解析，不會上傳或保存。

## 功能

- 整月份或自訂日期區間
- 自動計算應上工時，並允許手動修改
- 支援多個 `.xlsx` 檔（跨月區間）
- 讀取服務工時、交通時間、員工請假與個案請假
- 自動分類週六與國定假日工時
- 檢查週六是否超過 8 小時，並顯示超過時數
- 按週以工作日 × 8 檢查平日是否達應上時數；國定假日自動扣除
- 計算平日加班、應上不足與總加班
- 核對 Excel 表頭總計與每日加總是否一致
- 日期區間錯誤、不同員工混選與缺少月份防呆
- 日期區間模式會註明請假資料仍為 Excel 整月表頭值
- 非完整週或缺少相鄰月份時不進行單週判定

Excel 解析元件已放置於網站內，不依賴外部 CDN；所有檔案仍只在瀏覽器中處理。

## 隱私

使用 JSZip 在瀏覽器中直接讀取 XLSX 的 XML 內容，不會將試算表送到伺服器。
