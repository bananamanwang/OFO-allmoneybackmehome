# 服務員工時 Excel 驗算

網站抬頭：財團法人老五老基金會-工時計算(全自動版)。目前為第六版；總加班超過 46 小時時會以黑底紅字顯示警告。

純前端的服務紀錄總表驗算工具。Excel 檔案只在瀏覽器本機解析，不會上傳或保存。

## 功能

- 整月份或四週工時週期；四週模式只選第一天，自動計算至第 28 天
- 開啟時自動帶入目前月份及當下所屬的四週工時週期
- 自動計算應上工時，並允許手動修改
- 支援多個 `.xlsx` 檔（跨月區間）
- 讀取服務工時、交通時間、員工請假與個案請假
- 自動分類週六與國定假日工時
- 週六與國定假日／補假日期分區呈現，重疊日期只計算一次
- 提供 3 欄颱風假補貼分鐘，每欄上限 480 分鐘；加入期間總工時，但不列入總加班
- 未放入 Excel 前收合驗算區，成功讀取後才顯示結果
- 檢查週六是否超過 8 小時，並顯示超過時數
- 按週以工作日 × 8 檢查平日是否達應上時數；國定假日自動扣除
- 計算平日加班、應上不足與總加班
- 核對 Excel 表頭總計與每日加總是否一致
- 四週週期、不同員工混選與缺少月份防呆
- 四週模式會註明請假資料仍為 Excel 整月表頭值
- 非完整週或缺少相鄰月份時不進行單週判定

Excel 解析元件已放置於網站內，不依賴外部 CDN；所有檔案仍只在瀏覽器中處理。

## 隱私

使用 JSZip 在瀏覽器中直接讀取 XLSX 的 XML 內容，不會將試算表送到伺服器。
